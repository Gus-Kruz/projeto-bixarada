# Projeto Bixarada

Projeto da bixarada para a Cover JAM de 2026, o objetivo da jam é criar um jogo baseado em uma capa da Famicase.

# Ideia do jogo

O jogo vai ser multiplayer competitivo que mistura ritmo e combate. Inicialmente, cada jogador escolhe com qual personagem vai escolher, cada um tendo stats diferentes.

## Parte 1:

A primeira parte é um jogo de ritmo comum. Ao longo do jogo, algumas partes ficam ridiculamente absurdas, peronagens começam a se xingar, até a música acabar completamente. Os músicos vão cair na porrada.

## Parte 2:

A segunda (e verdadeira) parte do jogo envolve uma luta entre os personagens. Eles devem atacar e se movimentar no ritmo do jogo, o primeiro a zerar a vida perde!


# Inspirações:

- Os personagens inicias e seus instrumentos do jogo serão os representados na capa;
- O tema "Não julgue o livro pela capa" é cumprido quando há a quebra de expectativa na mudança na mecânica de jogo.
