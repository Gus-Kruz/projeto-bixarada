## Como adicionar issues:
Ao adicionar uma issue dê um título claro e descreva as features dela, algumas perguntas que você acha importante serem respondidas ao implementá-las.
As issues vão sendo adicionadas aos poucos e se você está fazendo algo que não tem uma issue atrelada sinta-se livre pra adicionar!
## Progredindo na issue:
Use o kanban para indicar em que issue você está trabalhando em que estado ela está.
Sempre que iniciar uma issue associe a branch em que você está fazendo as implementações para que colegas de função saibam como te ajudar!
A medida que as features vão sendo implementadas é importante atualizar a issue, para isso é recomendado o seguinte template:
> # Título
> features importantes da issue
>
> ## Título feature x
> descrição da feature x
> ## Título feature y
> descrição da feature y
> ...
> ## Encaminhamentos Futuros  
> features que ainda podem ser adicionadas
  
Obrigado ao luqhe pelo template!
## Finalizando uma issue:
Ao terminar todas as features de uma issue atulize o kanban e mostre pro seus colegas o que você implementou!
Com isso de merge das features na master e comemore!!
## Comunique:
Se sente algo está incrível, ruim, faltando algo, ou com coisa demais, fale com os seus colegas!!!
